## GitHub Pages upload
1. Unzip this archive.
2. Open https://github.com/sparkyradish/sw-decorating and choose **uploading an existing file**.
3. Upload `index.html`, `styles.css`, `script.js`, and optionally `README.md` from the unzipped folder. **Do not upload the ZIP itself.**
4. Commit the files to `main`.
5. Under **Settings > Pages**, select **Deploy from a branch**, branch **main**, folder **/(root)**.
6. Verify https://sparkyradish.github.io/sw-decorating/ before adding the custom domain.
7. In Pages settings add `www.sw-decorating.co.uk`; configure its CNAME with your DNS host to `sparkyradish.github.io`. Follow GitHub's instructions to configure the apex domain if needed. Preserve existing MX and other email DNS records.
