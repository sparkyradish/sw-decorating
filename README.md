# Warwickshire Decorating website

A responsive, one-page demonstration website built with HTML, CSS and JavaScript. No build tools are needed.

## Preview
Open `index.html` in a web browser. The website also works on mobile screens.

## Before publishing
1. Replace the temporary name **Warwickshire Decorating** with the decorator's genuine trading name in `index.html` (including title, meta description, header and footer).
2. In `script.js`, set `CONTACT_EMAIL` to the real business email address. The enquiry form prepares an email in the visitor's email application; it does NOT submit to a database or send messages on its own.
3. Check the services, coverage areas and all business claims against what the decorator actually provides.
4. Replace the image URLs with genuine, licensed project photos. All current photos are illustrative remote Unsplash images, not completed jobs.
5. Add real business contact details, any verified reviews, and legal information (such as privacy policy) as appropriate before launching publicly.
6. Upload all three files (`index.html`, `styles.css`, `script.js`) to the web host's public directory, preserving the filenames.

## Notes
- Google Fonts and Unsplash images require an internet connection.
- Navigation, mobile menu, responsive styling and email draft generation work without a server.
- For direct website submissions, connect the form to a real form provider or secure backend and add an appropriate privacy notice.
